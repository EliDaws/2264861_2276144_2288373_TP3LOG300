## Objectif du projet

Le projet est une calculatrice web simple faite en Python avec Flask. L'utilisateur entre une
opération (addition, soustraction, multiplication ou division) avec les boutons de l'interface et
le serveur calcule le résultat.

Le but du TP est de mettre de l'ordre dans le projet : configurer le dépôt GitHub, documenter le
code, ajouter des tests et corriger les bogues en utilisant des issues, des branches et des pull
requests.

## Prérequis

Avant d'installer le projet, il faut avoir :

- Git
- Python 3
- pip
- Flask

## Installation

1. Cloner le dépôt :

   ```bash
   git clone git@github.com:EliDaws/2264861_2276144_2288373_TP3LOG300.git
   cd 2264861_2276144_2288373_TP3LOG300
   ```

2. (Optionnel) Créer et activer un environnement virtuel :

   ```bash
   python -m venv venv
   source venv/bin/activate      # Sur Windows : venv\Scripts\activate
   ```

3. Installer Flask :

   ```bash
   pip install flask
   ```

4. Lancer l'application :

   ```bash
   python app.py
   ```

5. Ouvrir <http://127.0.0.1:5000> dans un navigateur.
